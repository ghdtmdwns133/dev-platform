# __PROJECT_NAME__

React + Vite + Sentry project generated by
[dev-platform](https://github.com/__OWNER__/dev-platform).

## Local workflow

```bash
npm ci
uv run --project .dev-platform/cli devctl verify --profile typescript
```

`devctl verify` runs `npm ci`, `tsc --noEmit`, eslint, prettier and vitest with
coverage, then enforces the coverage floor from `.devplatform/config.json`.

## Sentry

`src/instrument.ts` initializes Sentry from `VITE_SENTRY_DSN`. Builds upload
source maps only when `SENTRY_AUTH_TOKEN`, `SENTRY_ORG` and `SENTRY_PROJECT` are
present; the Vite plugin disables itself otherwise.

`npm run verify:sentry` starts a local envelope server, sends one event and
prints `envelope received`. `npm run verify:sentry -- --live` uses the real
`SENTRY_DSN` plus the auth token and confirms the event through the Sentry API;
it exits 2 when credentials are missing.

## CI

`.github/workflows/ci.yml` calls `quality.yml` and `security.yml` at
`__PLATFORM_REF__`. Both report independently as `platform-verify` and
`platform-security`. `copilot-setup-steps.yml` lets the Copilot cloud agent run
the same `devctl verify` command.

## Release automation

release-please opens a Release PR from conventional commits and labels it
`automerge`; merging it creates the tag and attaches the production `dist` zip.
