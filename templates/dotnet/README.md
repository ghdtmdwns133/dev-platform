# __PROJECT_NAME__

.NET solution generated by [dev-platform](https://github.com/__OWNER__/dev-platform).

## Local workflow

```bash
dotnet restore
uv run --project .dev-platform/cli devctl verify --profile dotnet
```

`devctl verify` runs restore, `dotnet build --no-restore -warnaserror`,
`dotnet format --verify-no-changes --severity warn`, `dotnet test` with XPlat
coverage, and the coverage floor from `.devplatform/config.json`.

## Toolchain

`global.json` pins SDK `10.0.401` with `rollForward: latestPatch`.
`Directory.Build.props` treats warnings as errors and enables the .NET
analyzers; `Directory.Packages.props` centralizes package versions.

## CI and release

`.github/workflows/ci.yml` calls the shared `quality.yml` and `security.yml`
workflows at `__PLATFORM_REF__`. release-please drives versioning through
`version.txt`; the Release PR is labeled `automerge`, and merging it publishes
the NuGet packages produced by `dotnet pack`.
