# __PROJECT_NAME__

Python project generated by [dev-platform](https://github.com/__OWNER__/dev-platform).

## Local workflow

```bash
uv sync --frozen
uv run --project .dev-platform/cli devctl verify --profile python
```

`devctl verify` runs the same steps as CI: `uv sync --frozen`, ruff check, ruff
format check, pytest with coverage, and the coverage gate from
`.devplatform/config.json`.

## CI

`.github/workflows/ci.yml` calls the shared `quality.yml` and `security.yml`
workflows at `__PLATFORM_REF__`. Required status checks are `platform-verify`
and `platform-security`; both report independently so a defect turns both red
at the same time.

## Release automation

Conventional commits drive release-please. Merging a Release PR creates a tag
and attaches the wheel and sdist built by `release.yml`.

## Adoption

1. Edit `.devplatform/config.json` for the coverage floor and reports path.
2. Fetch the platform locally with `bootstrap` or copy `.dev-platform` next to
   the project.
3. Run `devctl verify --profile python` before pushing.
